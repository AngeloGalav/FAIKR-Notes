# Question
1) Given the following LPAD program:
```
win_one_match(Team) :- win_over(Team, _).

win_over(scotland, czechRep):0.3.
win_over(scotland, holland):0.2.
```
Which is the probability of the query `win_one_match(scotland)` ?

The candidate should illustrate the Distribution Semantics by showing the “worlds”, 
the probability of each world, and the formula used to compute the overall probability.

## Answer
win_one :- win_over(scotland, czechRep)
win_one :- win_over(scotland, holland)

win_over(scotland, czechRep):0.3. (null : 0.7)
win_over(scotland, holland):0.2. (null : 0.8)


Lets compute the worlds first:
- w1
win_one :- win_over(scotland, czechRep) 0.3
win_one :- win_over(scotland, holland) 0.2
P(w1) = 0.3*0.2

- w2
null :- win_over(scotland, czechRep) 0.7
win_one :- win_over(scotland, holland) 0.2
P(w2) = 0.7*0.2

- w3
win_one :- win_over(scotland, czechRep) 0.3
null :- win_over(scotland, holland) 0.8
P(w3) = 0.3*0.8

- w4
win_one :- win_over(scotland, czechRep) 0.7
win_one :- win_over(scotland, holland) 0.8
P(w4) = 0.7*0.8

So, the probability of win_one_match(scotland) is the probability of all the situations in which scotland wins:
- 0.3\*0.2 + 0.3\*0.8 + 0.7\*0.2
= 0.44


# Question
2) The candidate is invited to briefly introduce the Knowledge Graph paradigms, and which are the main differences w.r.t. the Semantic Web proposal.

## Answer
The semantic web proposal is a proposal about using common formats for the integration of data and defining a language for defining how the data relates to real world object. 
This is done by extending the current web with knowledge about the content, called semantic information, and using description logics. 

Knowledge Graphs are another way to reason upon knowledge, in which graphs are used 

The main difference between KR and SW are:
- In KR there's no standard conceptual schema: data from various sources, with different semantics can be mixed freely 
- In KR there's no reasoning abount the knowledge: every possible consequence is calculated and stored. This is also implies that ABOXES and TBOXES are stored at same level with no separation.
