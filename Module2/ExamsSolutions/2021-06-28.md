# Question
The candidate is invited to write a prolog predicate count/2 that, given as input
a term representing a predicate, it will return the number of solutions for the
goal of proving that input predicate. For simplicity, it will be assumed that the
proof procedure of the predicate passed as parameter will always terminate in a
finite time.
For example:
```
p(a).
p(b).
p(c).
```
and the query:
```
count(p(X), Result).
```
The expected answer is:
```Yes, Result = 3.```

This is because there are three different ways for proving the goal p(X).

## Answer
```
count(A, Y) :- findall(_, call(A), S), length(S, Y).
```

# Question
2) The candidate is invited to introduce the RETE algorithm, and to show with a
short example in natural language the differences between inter-elements and
intra-elements patterns/features.

## Answer
LHS is usually expressed as a conjunction of patterns
• Deciding if the LHS of a rule is satisfied/is matched, consists on
verifying if all the patterns do have a corresponding element (a
fact) in the working memory
• It is a "many patterns" vs "many objects" pattern match problem


The RETE Algorithm is used in the Forward rule-based reasoning framework, and it is used to resolve queries. 
It focuses on the first step of the productions rule approach. 

Since LHS are usually expressed as a conjuction of patterns, deciding if the LHS of a rule is satisfied/is matched consists on
verifying if all the patterns do have a corresponding element (a fact) in the working memory.
This is the reason why we determine the so called "conflict set", the set of all possible instantiations of _production rules_ such that
"\<Rule (RHS), List of elements matched by its LHS\>".

In this way, we avoid iteration over facts by storing, for each pattern, which are the facts that match it. 

Idea: "compile" a LHS into a network of nodes. There at least two types of patterns:
1. Patterns testing intra-elements features
2. Patterns testing inter-elements features

- _Intra-elements_ patterns are compiled into alpha networks, and their outcomes are stored into alpha memories. 
- _Inter-elements_ are compiled into beta-networks, and their outcomes are stored into beta-memories.

After that, there's a conflict resolution step, in which we decide which rule to execute first, and the actual execution of the rule. 

Example: "When a student whose name is X, when a professor with name X, notify a warning to the deputy
head of the school"
student and professor are defined as intra-elements, while name is X (in both cases) are inter elements.
