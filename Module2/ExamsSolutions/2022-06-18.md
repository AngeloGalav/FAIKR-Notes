# Question 

1) The candidate is invited to present the notion of the cut “!” operator in the
Prolog language. Moreover, the candidate should illustrate its usage through a
very short example.

## Answer
The CUT operator in Prolog is a special operator which partially reduces the declaritiveness of the language, and has no logic semantics. 
Essentially, when this operator is evaluated, the choices of values for unification of the previous variable are made definitive and _non-backtrackable_.
In practice, the operator causes the choices in the backtracking stack to be deleted. 

Here's an example of the influence of this operator.
```Prolog
% A)
p(X) :- q(X), r(X)
p(1)
p(2)
r(2)

% B)
p(X) :- q(X), !, r(X)
p(1)
p(2)
r(2)
```
The query `?- p(X)` returns X = 1 in the the program A), but in program B) it causes  a fail. This is because the program chooses the value `X = 1` first for the unification. 


# Question

2) The candidate is invited to briefly introduce the Knowledge Graph paradigms, and
which are the main differences w.r.t. the Semantic Web proposal.

## Answer
The semantic web proposal consists on creating a common format for integration of data, and developing a language for recording and describing how the data relates to real world objects. 
This is done by extending the current web with knowledge about the content, called semantic information, and using description logics.

The proposed semantic web technologies (such as OWL and RDF) are too slow and complex. So, the idea of Knowledge Graph was introduced. 
Essentially, knowledge graphs consists on graph-based structures such that information is stored in terms of nodes and arcs connecting to nodes.   
In KG, facts and axioms (TBOX and ABOX) are stored in the same level, and instead of reasoning upon them, every consequence possible is stored, in order to save time. 

Also, there's no conceptual schema: data from various sources can be mixed up freely.  

The main difference between KR and SW are:
- In KR there's no standard conceptual schema: data from various sources, with different semantics can be mixed freely 
- In KR there's no reasoning about the knowledge: every possible consequence is calculated and stored. This is also implies that ABOXES and TBOXES are stored at same level with no separation.
