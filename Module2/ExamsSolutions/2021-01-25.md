# Question
The candidate is invited to shortly introduce rule-based forward reasoning and the RETE algorithm. 

## Answer
Forward rule-based reasoning is a framework for reasoning which is comprised of rules, as a way for representing knowledge.
The main characteristic of this type of framework is the use of a Working Memory, which is a data structure that allows for new facts to be added dynamically to the Knowledge base, without having to restart reasoning from scratch. 

The RETE Algorithm focuses on determining the so called "conflict set", 
the set of all possible instantiations of production rules such that
"\<Rule (RHS), List of elements matched by its LHS\>".

Idea: avoid iteration over facts by storing, for each pattern, which are the facts that match it. 
- When a new fact is added or modified, all the patterns are confronted, and the list of matches is updated

Idea: "compile" a LHS into a network of nodes. 
(At least) Two types of patterns:
1. Patterns testing intra-elements features
2. Patterns testing inter-elements features

- _Intra-elements_ patterns are compiled into alpha networks, and their outcomes are stored into alpha memories. 
- _Inter-elements_ are compiled into beta-networks, and their outcomes are stored into beta-memories. 

After that, there's a conflict resolution step, in which we decide which rule to execute first, and the actual execution of the rule.

```
evaluated to true if Goal can be proved; moreover, after having solved any subgoal, the meta-interpreter must print (at the standard output) the sub-goal itself.
Hence, only goals that have been proved will be printed at the output.
For example, given the program:

p(X) :- s(X).
q(X) :- t(X).
r(1).
r(2).
r(3).
t(1).
t(2).
and the query ?- verbose(p(X)), the following outcomes are expected:
?- verbose(p(X)).
Solved: t(1)
Solved: q(1)
Solved: r(1)
Solved: p(1)
X = 1 ;
Solved: t(2)
Solved: q(2)
Solved: r(2)
Solved: p(2)
X = 2 ;
```

## Answer
```Prolog
solve(true) :- !. 
solve((A, B)) :- !, solve(A), solve(B). 
solve(A) :- clause(A, B), solve(B), write("Solved: "), write(A). 
```

### Remarks
- if in `solve(A)` you would have written "write("Solved: "), write(B)", then you would have always printed the __tail__ of the solved prepositions.
