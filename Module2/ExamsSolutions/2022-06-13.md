strategy).

## Answer

```
solve(true) :- !.
solve( (A, B) ) :- !, solve(A), solve(B).
solve(A) :- clause(A, B), solve(B).
```
I've told the description twice already, so I'll skip it for now. 

A possible meta-interpreter, with modified SLD is this:
```
solve(true) :- !.
solve( (A, B) ) :- !, solve(B), solve(A).
solve(A) :- clause(A, B), solve(B).
```
This changes the SLD resolution system form leftmost to rightmost. 

# Question

2) The candidate is invited to shortly describe the RETE algorithm.

## Answer
The RETE algorithm is an algorithm used to implement the production rules approach, used in Forward reasoning. 
It essentially focuses on the "match" step of the Production Rules system.

In order to determine efficiently which rules should be triggered at any given time, RETE creates a conflict set, which contains all the possible instations of production rules such that:
`<Rule (RHS), List of elements matched by its LHS>`.
In this way, the iteration over the facts is avoided, and instead for each pattern the facts that match it are stored. 

The RETE algorithm also compiles the LHS into a network of nodes, and distinguishes between inter-elements and intra-elements in certain rule.

The intra elements are compiled into alpha nets, and their outcomes is stored into alphamemories, while inter elements are compiled into beta nets.   

In the end, the beta memory contains the conflict set.
