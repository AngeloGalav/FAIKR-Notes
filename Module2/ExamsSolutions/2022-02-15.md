# Question

1) The candidate is invited to illustrates the meaning of the meta-predicate `findall`.
The candidate is also invited to illustrates the use of the predicate by means of an
example.

## Answer
The meta-predicate is defined in this way:
`findall(X, P, S)` : returns in S all elements all values of X such that P is true. 
S is defined without repetition of values.   
i.e. 
```
father(jack, mary).
father(jack, mario).
father(mario, luigi).
```

Unlike `setof`, in this situation the predicate `findall` would return all possible values of X such that P is true. So, it returns the whole list of father, rather than a single father.
So, 
```
?- findall(X, father(X, Y), S)
S = [jack, mario]
```  

essentially, if `setof` has a free variable, then it unifies that variable with a single possible value of Y. 
On the other hand, `findall` finds also all the possible variables for that free variable. 


# Question

2) The candidate is invited to introduce the “ontology” and the domain independent axioms of the Event Calculus framework.

## Answer

The ontology:
- __HoldsAt( F, T )__: The fluent F holds at time T
- __Happens( E, T )__: event E (i.e., the fact that an action has been executed) happened at time T
- __Initiates( E, F, T)__: event E causes fluent F to hold at time T (used in domain-dependent axioms…)
- __Terminates( E, F, T)__: event E causes fluent F to cease to hold at time T (used in domain-dependent axioms…)
- __Clipped( T1, F, T )__: Fluent F has been made false between T1 and T(used in domain-independent axioms), T1< T
- __Initially( F )__ : fluent F holds at time 0

The domain independent axioms:
Axioms for defining if a fluent is true
- $HoldsAt(F, T) \leftarrow Happens(E, T_1) \land Initiates(E, F, T_1) \land (T_1 \lt T) \land ¬Clipped(T_1, F, T)$
- $HoldsAt(F, T) \leftarrow Initially(F) \land ¬Clipped(0, F, T)$

Axiom for defining clipping of the fluent:
- $Clipped(T_1, F, T_2) \leftarrow Happens(E, T) \land (T_1 < T < T_2) \land Terminates(E, F, T)$
