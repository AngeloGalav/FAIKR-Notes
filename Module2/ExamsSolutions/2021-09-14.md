# Question
1) The candidate is invited to describe how negation is tackled in Prolog, what is
NAF, what is SLDNF, and the issues related with NAF over terms containing unbounded variables.

## Answer
Since the proof of queries which are not a logical consequence of a clause can lead to non-convergence, Prolog adopts NAF (Negation as failure) instead of the more powerful CWA (Closed world assumption). 

Essentially, NAF consisting in proving a negated query (i.e. ~A) by trying to prove the same query without the negation (i.e. A).
- if A is proved, then ~A fails. 
- if A fails, then ~A is not proved.   

SLDNF is the name of the implementation of NAF in Prolog's SLD resolution, which is the process of determining the substitution of variables in the goal.  

Since mixing NAF with variable quantification can be a problem, SLDNF is applied only to ground rules (so in clauses where there are no free variables). To implement this, we first select predicates which do not have variables, and implement the rest later. 


# Question
2) The candidate is invited to describe the distribution semantics adopted in LPAD,
using also a short program to illustrate such semantics.

## Answer
LPAD is a way to implement a probability distribution over normal logical program, so that we can compute the probability of a query. 

In LPAD, the head of each clause is annotated with a probability, and the actual probability of the query is computed by summing the probability of each world in which _the query is true_.

The distribution semantic is defined as:
\[P(k) = \prod_{(C, \theta, i) \in K} P(C, i)\]

where C is a clause, $\theta$ is a substitution such that C$\theta$ is ground, (C, $\theta$, i) is an atomic choice of head C and body i,  and K is the set of atomic choices.
