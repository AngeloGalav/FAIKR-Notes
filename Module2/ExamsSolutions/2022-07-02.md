# Question
The candidate is invited to define a Prolog meta-interpreter solve(Goal) that
solves the given Goal, but using a right-to-left selection rule of the subgoal to be
solved instead of the usual left-to-right rule

For example, given the following knowledge base:
```p(1) :- write('I am solving P.').
r(1) :- write('I am solving R.').
q(X) :- p(X), r(X).
```

and the goal:

```
:- solve( q(X) ).
```
The expected outcome is:
```
I am solving R.
I am solving P.
Yes, X/1.
```

## Answer
This is the easiest fucking exercise ever. 
Whoever received this whole exam was so fucking lucky I swear, it's unbelievable. I know it will never happen to me, and this is the reason I'm studying so much. 

```
solve(true):- !.
solve( (A, B) ) :- !, solve(B), solve(A).
solve(A) :- clause(A, B), solve(B).
```
This is the solution. 

# Question
2) The candidate is invited to describe the predicates/terminology used in the
definition of the Event Calculus Framework.

## Answer
I believe he's asking about the ontology of Event Calculus.
The ontology of Event Calculus is comprised of 6 predicates:
- HoldAt(F, T) : Fluent F is true at time T.
- Initiates(E, F, T): Fluent F is instantiated by event E at time T
- Clipped(T1, F, T2): Fluent F ceases between time T1 and T2. 
- Initially(F): Fluent F is true at time 0
- Terminates(E, F, T): Fluent F is terminated by event E at time T
- Happens(E, T): event E happens at time T. 

Just for fun, let's also list the axioms.
2 axioms for defining when a fluent is true:
HoldsAt(F, T) <= Initially(F) && ¬Clipped(0, F, T)
HoldsAt(F, T) <= Happens(E, T1) && Initiates(E, F, T1) && (T1 < T) && ¬Clipped(T1, F, T) 

1 axiom for defining the behaviour of clipping:
Clipped(T1, F, T2) <= Happens(E, T) && (T1 < T < T2) && Terminates(E, F, T)
