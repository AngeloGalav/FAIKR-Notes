# Question 1
The candidate is invited to define a Prolog predicate `filter/3` that receives in input two lists L1 and L2 (all containing group elements) and returns in output a list L3. The list L3 will contain all the elements appearing in both L1 and L2, but without repetitions. 
The candidate should report any auxiliary predicate that will be used in the solution. 

For example, if invoked with:
`:- filter([1,3,4,3], [4,5,3,7,3], L3)`
The expected outcome is:
`Yes, L3/[4, 3]`

## Answer 
```
filter(L1, L2, S) :- findall(X, (memberOf(X, L1), memberOf(X, L2)), S).

memberOf(H, [H | _]).
memberOf(X, [_ | L]) :- memberOf(X ,L).
```

# Question 4
The candidate is invited to briefly introduce the notion of Semantic Networks, and to highlight some of the limits that were present in their original formulation. 

## Answer 
Semantic networks are a way to represent knowledge, in particular by using a directed graph to represent relationship between object and categories. 
Each node of the graph represent either a category or an object, and links represent relationships between them. 

The main problem with this formulations are:
- The "diamond problem" caused by multiple inheritance, which could introduce ambiguity in the value of some properties of categories. 
- (not original), the loss of declaritiveness that can arise from attaching a piece of code to a link.
