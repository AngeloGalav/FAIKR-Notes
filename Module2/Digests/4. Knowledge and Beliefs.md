As of now, the viewpoint of an agent with KB has some limits.

In the environment there are other agents:
- Success of any decision depends on the actions taken by other agents 
- These others agents might have their own knowledge… 
- … knowing something about the others might help to take our own decisions? 
 
Our agent has a KB, but it does not know it:
- no distinction between knowledge, belief, perception, … 
- no possibility of any meta-reasoning on its own knowledge

## Propositional attitudes
Propositional attitudes behave differently from predicates, and using FOL predicates is not the best choice ("does not work"). For example:
- Propositional attitudes refer to something that is not a term.
	- Knows(Federico, location(pizza, fridge)). location(pizza, fridge) is usually a sentence, not a term.
- FOL predicates might support referential transparency
	- Knows(Lois, CanFly(Superman)). Superman=Clark.
	- Does that mean that Lois knows that Clark can fly? NO.

## Modal operators
The idea was to introduce new, special operators, named ___Modal operators___, that behaves differently from logical operators.

Modal Logics:
- same syntax as FOL, augmented with modal operators 
- modal operators take ___sentences___ as input (rather than regular terms) 
- each modal operator takes two inputs: 
	- the name of an agent, and the sentence it refers to 
- Semantics is extended with the notion of _possible worlds_. 
- _Possible worlds_ are related through an accessibility relation (that might depend on the operator) 
- Different operators define different logics.

Example: operator $\textbf{K}$ for indicating that agent $a$ knows $P$:
$$
\textbf{K}_aP
$$
- Federico knows there is a pizza in the fridge 
	- $\textbf{K}_{federico}location(pizza,fridge)$ 
- Federico knows that Elena knows that there is a pizza in the fridge 
	- $\textbf{K}_{federico}\textbf{K}_{elena}location(pizza,fridge)$

# Modal Logics 

The starting point: ==an agent in a given scenario is not __omniscient__== regarding all the aspects of the current state of the world (the current world). Thus, an agent might think: 
- there is the current perception of the state of the world 
- the unknown is depicted as possible worlds, with an intuitive notion of possibility or accessibility from my current world 
 
We are not really interested on a specific notion of "accessibility": it might suffice that there is such a notion. The idea is something like: an agent knows $p$ if in any accessible world accessible from the current, $p$ is true.

##### Formally...
Given a set of primitive propositions $\phi$ , a ___Kripke structure___ $M=(S, \pi, K_1,\dots,K_n)$ is defined: 
- $S$ is the set of states of the world 
- $\pi: \phi → 2^S$ specifies for each primitive proposition the set of states at which the proposition holds (that is, is true).
- $K_1, \dots, K_n$ are binary relations over $S$, i.e. $K_i \subseteq S \times S$, with the meaning: $(s,t) \in K_i$ if agent i consider the world t possible from s. 

> [!warning ]
> The binary relations $K$ are DIFFERENT from the Modal operator $\textbf{K}$ , even though Chesani used a similar symbol for both of them. 
> 
> THEY ARE COMPLETELY DIFFERENT CONCEPTS. 

- Don't get confused by the accessibility/possibility relation: we are not really interested in it

### Properties of the knowledge modal operators 
Axioms of our logic:
- __A0__: All instances of propositional tautologies are valid.
- __MP__ (modus ponens): if $\phi$ is valid and $\phi \Rightarrow \psi$ is valid, then also $\psi$ is valid.
- __A1__ (distribution axiom): $(K_i\phi \land K_i(\phi\Rightarrow\psi))\Rightarrow K_i\psi$, which measn that knowledge is closed under implication.
- __G__ (Knowledge Generalization Rule): for all structures $M$, if $M ⊨ \phi$ , then $M\models K_i\phi$. 
	- In other words, our agent knows all the tautologies. 
	- This of course holds for tautologies only… i.e., $\phi \rightarrow K_i\phi$ is not valid (unless we axiomatize it).
- __A2__ (Knowledge Axiom): If an agent knows $\phi$ , then $\phi$ is true. $(K_i\phi \Rightarrow\phi)$
	- ==This is considered to be the central property of Modal logic for knowledge== (valid only if the possibility/accessibility relation is reflexive). 
	- What about belief? This axiom, in belief logic, does not hold. It is usually substituted by: A2': $(¬K_ifalse)$.
- __A3__ (positive introspection): $(K_i\phi \Rightarrow K_iK_i\phi)$
- __A4__ (negative introspection): $(\neg K_i\phi \Rightarrow K_i \neg K_i\phi)$
	- The agent might have a partial knowledge of the world (hence the possible worlds), but with these axioms we get sure that at least it has perfect knowledge about its own knowledge.

Different Axioms define different logics.

# Linear-time Temporal Logic (LTL)
The world observed by an agent evolves through time… the framework of modal logic has been exploited to support a qualitative representation and reasoning over the evolution of worlds along the temporal dimension. 
- The accessibility relation now is mapped into the temporal dimension 
- each world is labelled with an integer: time is then discrete 
 
Two possible ways for the world to evolve: 
- Linear-time: from each world, there in only one other accessible world 
- Branching-time: from each world, many worlds can be accessed

### Model Checking
LTL (but also CTL) lend themselves nicely to the modelling of system specifications that can be considered as _finite state machines_. In other words, this shit can actually be used irl. 

They proved quite effective also in __modelling distributed systems__, where different agents can exchange messages and information. 

A question arises: given a specification of a (distributed) system, is it possible to prove that some properties always/sometimes hold?
- Is it possible to prove that a certain state will never occur? (safety properties) 
- Is it possible to prove that a certain state will occur, sooner or later? 
- Is it possible to prove that my system will not end up in a loop? (livelock/deadlock)

Model Checking is a discipline that investigated the possibility of proving such formal properties. 

Many approaches and tools have been proposed, among them many tools adopted the LTL semantics. 

Many applications fields benefitted from these techniques: 
- hardware design 
- safety-critical systems 
- safety-critical processes and operations 
- security protocols

Each model __is not guaranteed to terminate since it is based on FOL__. What we can do is base ourself on __propositional logic__ instead, which is guaranteed  to be decidable.
